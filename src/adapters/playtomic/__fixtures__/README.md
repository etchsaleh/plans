`availability_battersea_2026-11-21.json` has the **response shape** recorded on 2026-11-20 from the request that
playtomic.com's public club page (`/clubs/battersea-park-millennium-arena`) makes to
`/api/clubs/availability?tenant_id=…&date=…&sport_id=PADEL`. The resource ids and shape are real. The slot
times and prices were edited to build test cases.
